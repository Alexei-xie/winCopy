# winCopy 1.1 界面设计

## 产品目标

把高频流程缩短为“呼出 → 找到 → 粘贴”。历史和片段保留各自的浏览方式，搜索始终置顶；主操作固定在右下角，低频设置放在更多菜单。

## 视觉规范

- 浅灰紫画布、白色内容表面、低饱和紫色主操作，深色正文。
- 面板圆角约 18 px、内容区域约 14 px、按钮和输入框约 10 px。
- 顶部品牌和状态、搜索、分类、历史列表、内容预览、操作栏形成固定层级。
- 列表以图标、内容摘要、类型/时间/来源分层；当前选中项使用浅紫底与细边框。
- 主操作“粘贴”使用实色按钮；复制、收藏、新建片段使用白底次级按钮。
- 按钮支持悬停、按下和键盘焦点；设置使用开关表达启用/关闭状态。
- 设置、片段窗口沿用原生窗口管理和键盘交互，内部采用相同圆角控件。

## 布局和兼容性

弹窗默认 480×680。分组溢出可横向浏览，排序和位置保留。设置内容可滚动，操作栏独立；片段操作栏使用自适应高度，避免按钮被裁切。

自绘控件继承 Button、CheckBox，保留点击、键盘与原生角色。文本输入仍使用 Windows 原生编辑控件，外层负责边框和圆角。

## 已验证

- 主面板、设置、片段窗口截图检查。
- 新建/编辑片段的最小窗口与 100% / 125% / 150% / 200% 模拟缩放，保存/取消行为。
- 设置按钮在正常、小窗口与 150% 模拟缩放下保持可见。
- 分组拖拽、筛选、弹窗拖动、布局持久化及存储自测。

模拟缩放不等同于真实高 DPI、多屏或辅助功能验收，这些仍需真机测试。
